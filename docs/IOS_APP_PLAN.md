# The iPhone app (BUSINESS_FEEDBACK_1021_PLAN B2, as the owner meant it)

**Asked (owner, 2026-10-21).** A real iPhone app, not the website added to the home screen. The PWA built first
(branch `ux/b2-pwa`) is not it and is not merged.

**Constraints.**

- No Mac here (this server is Linux) and the owner's Mac is not at hand: the app is built and run in Apple's iOS
  Simulator on **GitHub Actions' macOS runners**, free for the public repository `batman1m2001-cyber/mr-finance`
  (`origin`; never `mymy`). The owner lets me push the `app/ios` branch; `main` stays the owner's to push.
- **No paid Apple Developer account.** Simulator builds need no signing. Later, on real phones: one build from a Mac
  with a free Apple ID (installs on a phone plugged into that Mac, renewed every 7 days), no code change.
- **Clicking through it:** Appetize.io streams the simulator build in a browser (free tier, few minutes a month; the
  owner signs up). Used for demos, not for testing.

## The app

- **Native SwiftUI**, iOS 17+, no third-party package: Swift Charts for the charts, `URLSession` for the server.
  The project is described in `ios/project.yml` and generated by XcodeGen on the runner (no hand-written
  `.pbxproj`).
- **The same server as the website** (`https://oneweath.ngrok.app`, a setting): the same sign-in (session cookie),
  the same answers, so every figure equals the website's. No endpoint is added for the app.
- **The client's screens**, one tab each:

| Tab | Shows | Server |
|---|---|---|
| Đăng nhập (before the tabs) | the demo accounts of the client role; email and password | `GET /api/auth/accounts`, `POST /api/auth/demo`, `POST /api/auth/login`, `GET /api/auth/me` |
| Tổng quan | net worth and its month change, the month's money in and out, allocation, risk against the limit, the reserve | `POST /api/dashboard` |
| Tài sản | every holding grouped by class, value, cost, profit and loss, source | `POST /api/dashboard` (holdings) |
| Dòng tiền | 6 months past and 12 ahead (chart), this month's in and out by category, large payments ahead, recurring items | `POST /api/dashboard` (cashflow), `POST /api/flows` |
| Tin tức | each effective news impact on the family: expected change at 3 months, the P10–P90 band, by asset class | `GET /api/families/<id>/impact` |
| Trợ lý | the assistant: question, answer, the steps it took, suggestions | `POST /api/assistant` (`message`, `conversation_id`) |

- **The look:** B3's calm client look, natively: light by default (dark when the phone is dark), the system font
  with Dynamic Type, figures large and plain, VND as the website writes it (`43,5 tỷ`, `−90 triệu`).

## Checks

- **Every push to `app/ios`** runs `.github/workflows/ios.yml` on `macos-15`: XcodeGen → `xcodebuild` for the
  simulator → the unit tests (the money and date formatting, the decoding of the saved real answers in
  `ios/OneWealthTests/Fixtures`) → the app booted in an iPhone simulator once per screen, signed in as the demo
  client (`MF_DEMO=C01`, a launch setting of the simulator build only) → a screenshot per screen, light and dark →
  the screenshots and the zipped `.app` (for Appetize) as the run's artifacts.
- I read every run's screenshots (`gh run download`) before calling a step done.
