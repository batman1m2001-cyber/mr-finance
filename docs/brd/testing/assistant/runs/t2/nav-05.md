# nav-05 — Tải sao kê lên thế nào

Category: navigation · persona: chủ doanh nghiệp, bận (C02) · BRD: OWN-AS-02, BRIEF-DATA-01

How to add a statement, and whether a PDF works.

## Turn 1

**Người dùng:** Làm sao để tải sao kê ngân hàng lên app?

*Công cụ:* huong_dan · *trạng thái:* ok · *chế độ:* model · 3.5 s · US$0.00169

**Trợ lý:**

Bạn tải sao kê ở trang **Tài sản**:

1. Mở trang Tài sản (menu hoặc nút bên dưới).
2. Chọn tệp PDF, Excel hoặc CSV của công ty chứng khoán hoặc ngân hàng.
3. Các khoản đọc được sẽ hiện với nhãn “Từ sao kê”.

Bạn có muốn tôi mở trang Tài sản cho bạn không?

**Kiểm tra:** đạt

## Turn 2

**Người dùng:** File PDF chụp bằng điện thoại thì có được không?

*Công cụ:* huong_dan · *trạng thái:* ok · *chế độ:* model · 5.0 s · US$0.00213

**Trợ lý:**

Hướng dẫn của ứng dụng chỉ nói là nhận tệp **PDF, Excel hoặc CSV**. Nó không nói rõ PDF chụp bằng điện thoại (ảnh quét) có đọc được hay không, nên tôi chưa thể khẳng định.

Bạn có thể thử tải lên. Nếu các khoản không hiện với nhãn “Từ sao kê”, thì tệp đó chưa được đọc. Khi đó, bạn nên tải sao kê dạng PDF xuất từ ứng dụng hoặc website ngân hàng, hoặc file Excel/CSV nếu có.

**Kiểm tra:** đạt
