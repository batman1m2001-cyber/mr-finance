# The assistant stress test — defects

Every defect below was found in a transcript of a real conversation (the served copy on :8041, the real model) or on
a real server whose dependency was really absent (:8042), and confirmed by reading it and, where it is a figure, by
recomputing it. Severity as in `docs/ASSISTANT_STRESS_PLAN.md` S5. Each fixed defect has a regression test in
`tests/test_assistant_stress.py` (named `test_dNN_…`), checked to fail without its fix where the fix is code.

Ranked by severity, then by how many customers meet it.
