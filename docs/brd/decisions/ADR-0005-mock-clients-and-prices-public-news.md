# ADR-0005 — Mock clients and prices, public news, a mock restricted list

- **Status:** accepted
- **Date:** 2026-10-09 (data), 2026-10-15 (news)
- **Sources:** docs/PLAN.md D1; docs/NEWS_IMPACT_PLAN.md A2, A5

## Context

The project uses no Techcombank data. A demo must run anywhere (docs/PLAN.md D1).

## Decision

- Five sample clients and two spouses (`data/clients/`, generated by `scripts/make_fixtures.py`), a mock market on 2026-10-09 (`data/market.json`), mock house views and advisory records — every file says so in its `note`.
- News is real: public RSS feeds on a white list (`data/news_config.json`). The restricted list holds invented names (Sao Mai Land, Hòa Bình Energy, Kim Phát Holdings).
- Every page's footer says the client data and prices are mock and the model parameters assumed.

## Consequences

- Ranking and BR-09 run over 7 people, not the BRD's 20 families or the bank's 6,500 (Q-18); NFR-01's scale is untested.
