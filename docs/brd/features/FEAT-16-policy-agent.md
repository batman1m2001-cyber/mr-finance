## What the BRD asks
An agent that summarises source-verified public policy documents and quotes their articles exactly; it sees no
portfolio and draws no conclusion for any family (§8 table). “Radar chính sách” is named but not described (Q-09).
The BRD's data model has `policy_documents` and `policy_matches`.

## Related existing capability
The pre-BRD policy-cost alerts (FEAT-25) hold 14 dated policies with a status and a source line, written by hand
in `data/factors.json`, not by an agent.
