## What exists
- The factor model is a versioned file (`data/factor_model.json`, `FM-DEMO-2026-10`, hashed; every run stores
  the whole model in its snapshot).
- The news configuration is a versioned file (`data/news_config.json`, `NEWS-DEMO-2026-10`): sources, white list,
  factor words, event types, the mock restricted list, gates.
- The prompt version is a constant (`PROMPT_VERSION = "v1"`); models come from environment variables.
- Both files are generated by scripts (`scripts/make_factor_model.py`, `scripts/make_news_config.py`); a change
  is a code change reviewed in git.

## What is missing (BRD)
No `config_versions` table; no owner per kind; no propose → confirm flow; no two-person rule; no UI to edit;
thresholds (the −5 % pre-review, post-check limits) are constants in `src/apply/run.py`.
